# ZEXO

A responsive, black-and-white discovery homepage for a Minecraft Bedrock add-ons community.

## Included
- Responsive landing page and category navigation
- Creator access contact link
- GitHub Actions workflow for GitHub Pages

## Publish
1. Open **Settings → Pages** in this repository.
2. Set the build and deployment source to **GitHub Actions**.
3. Pushes to `main` will deploy the static site.
4. The public URL will appear in the Pages settings and workflow deployment.

## Roadmap
Creator accounts, uploads, moderation, searchable add-on listings, download hosting, and offline sync require a backend and secure file storage.

Never put storage secrets or private API keys in frontend code.
